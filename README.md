# DJI 航线生成器 V2 (DJI Waypoint KMZ Generator V2)

一个基于 Vue 3 + CesiumJS 的 DJI 无人机航线规划工具，支持生成符合 WPML 1.0.6 标准的 KMZ 航线文件，可直接导入大疆司空 2 (DJI FlightHub 2) 和 Matrice 系列无人机。

V2 版本围绕航点航线编辑、本地化生成和稳定地图加载做了专项优化，让航线规划流程更轻、更快，也更适合本地部署和现场使用。

## V2 版本说明

### V2 版本优势

- **航点编辑更聚焦**：围绕航点航线常用流程优化交互，创建、编辑、预览和导出路径更直接。
- **虚拟飞行更直观**：支持按航线进行虚拟飞行预览，在生成前模拟无人机沿航点飞行的过程。
- **云台预览更准确**：可在编辑阶段查看云台俯仰角、相机视场和拍摄覆盖效果，提前判断航点动作是否合理。
- **本地生成更方便**：KMZ 文件可直接在浏览器中生成并下载，适合现场快速出线、快速验证。
- **地图加载更稳定**：Cesium 使用本地静态资源加载，减少外网、代理或 CDN 访问失败对地图初始化的影响。
- **定位体验更顺手**：进入地图后可自动定位本机位置，并将地图视角切换到当前位置，减少手动查找区域的步骤。
- **界面结构更完整**：首页和创建弹窗保留多航线类型展示，用户能清楚看到系统规划方向和后续扩展入口。
- **部署更轻量**：运行链路更简洁，对外部服务依赖更少，更适合本地环境、内网环境和演示环境部署。
- **司空兼容性延续**：继续生成符合 DJI WPML 规范的 KMZ 文件，可用于大疆司空 2 和 Matrice 系列无人机工作流。

## ✨ 核心功能

### 🗺️ 航线规划
- **可视化地图编辑**：基于高德地图 + CesiumJS 的 3D 地图界面
- **当前支持航线类型**：
  - **航点航线**：在地图上添加航点，配置高度、速度、云台和动作，生成 KMZ 文件
  - **其他航线类型**：面状、带状、斜面、几何体、巡逻等入口保留但暂不可用
- **航线类型展示**：保留原有多航线类型卡片，用灰色禁用态表示暂不可用能力
- **实时预览**：航线路径实时显示，支持航点路径编辑
- **坐标系转换**：自动转换 GCJ-02（高德）和 WGS84（GPS）坐标系

![商业版航线类型展示](doc/images/business-route-types-gallery.png)

### 🎥 虚拟飞行与云台预览
- **虚拟飞行预览**：沿航点航线模拟飞行过程，提前观察航线执行效果。
- **云台姿态预览**：展示云台俯仰角、航向角和相机朝向，便于检查拍摄动作。
- **相机视场预览**：结合相机参数和飞行高度展示视场范围，辅助判断覆盖是否满足任务需求。
- **航点动作校验**：在编辑阶段直观看到拍照、录像、云台动作等配置效果，减少导出后反复修改。

![云台预览与虚拟飞行](doc/images/gimbal-preview-virtual-flight.png)

### 🧭 本地定位和地图加载
- **自动定位本机位置**：地图初始化后会请求浏览器定位权限，定位成功后自动切换到当前位置。
- **本地 Cesium 资源**：Cesium 从 `/Cesium/Cesium.js` 加载，不再访问 unpkg CDN。
- **视角切换更直接**：定位成功后自动调整地图相机，方便快速进入作业区域。

### 📦 本地 KMZ 生成
- **本地下载**：点击生成后直接下载 KMZ 文件。
- **本地化工作流**：航线文件生成后即可保存到本机，便于交付、备份和导入司空。
- **后端直出文件流**：如使用后端生成接口，会直接返回 KMZ 文件流。

### 📐 高度模式
- **海拔高度 (WGS84)**：绝对海拔高度，基于 WGS84 椭球
- **相对起飞点高度**：相对于起飞点的高度
- **相对地形高度 (实时仿地)**：实时跟随地形起伏，保持相对地面高度恒定

### 🎯 任务配置
- **飞行参数**：速度、高度、起飞安全高度
- **失控动作**：返航、悬停、降落、继续执行
- **完成动作**：返航、降落、悬停、返回首航点
- **爬升模式**：垂直爬升、倾斜爬升

### 📦 KMZ 导入导出
- **导出 KMZ**：生成符合 WPML 1.0.6 标准的 KMZ 文件
- **导入 KMZ**：解析现有 KMZ 文件，恢复航线和配置
- **兼容性**：完全兼容大疆司空 2 和 Matrice 系列无人机

## 📖 使用指南

### 1. 绘制航线

#### 航点航线
1. 选择“航点航线”类型
2. 在地图上点击添加航点
3. 设置航点参数（速度、高度、云台角度、航点动作）
4. 预览航线路径和航点列表
5. 生成并下载 KMZ 文件

#### 其他航线类型
面状航线、带状航线、斜面航线、几何体航线和巡逻自动规划入口会继续显示在创建弹窗中，但 V2 版本中均为灰色禁用状态，暂不能进入编辑器。

### 2. 配置参数

#### 基础参数
- **飞行速度**：1-15 m/s，推荐 10 m/s
- **飞行高度**：20-500 m，推荐 60 m
- **起飞安全高度**：10-200 m，推荐 20 m

#### 高度模式选择
- **海拔高度**：适用于地形平坦区域
- **相对起飞点**：适用于起飞点和目标区域高度相近的场景
- **实时仿地**：适用于山地、丘陵等地形起伏较大的区域

### 3. 生成 KMZ

1. 点击 **生成 KMZ** 按钮
2. 文件会在浏览器中自动下载（`mission.kmz` 或以航线名称命名的 `.kmz` 文件）
3. 导入大疆司空 2 或无人机遥控器

### 4. 导入 KMZ

1. 点击 **导入 KMZ** 按钮
2. 选择已有的 KMZ 文件
3. 系统自动解析并恢复航线和配置

### 5. 本地定位

1. 打开页面后允许浏览器定位权限
2. 地图初始化完成后会自动飞到本机当前位置
3. 如果浏览器拒绝定位，仍可手动拖动地图和创建航点

## 🔧 核心逻辑

### 坐标转换
项目实现了 GCJ-02（火星坐标系）和 WGS84（GPS 坐标系）之间的相互转换：

- **存储**：使用 GCJ-02 坐标（与高德地图一致）
- **显示**：直接使用 GCJ-02 坐标（无偏移）
- **导出**：转换为 WGS84 坐标（大疆标准）

这确保了：
- ✅ 前端点击位置和显示位置完全一致
- ✅ 导入大疆后位置准确无偏移

### 航点航线生成
V2 对航点航线生成链路做了聚焦优化：

1. **航点编辑**：用户在地图上添加航点，并配置高度、速度、云台和动作。
2. **参数归一化**：生成前统一规范任务配置，减少参数遗漏和导出差异。
3. **坐标转换**：导出时将地图坐标转换为 DJI 航线文件需要的 WGS84 坐标。
4. **WPML 生成**：生成 `template.kml` 和 `waylines.wpml`。
5. **KMZ 打包**：使用 JSZip 打包为 KMZ 文件。
6. **本地下载**：浏览器直接下载生成结果。

### 距离和时间计算
使用 **Haversine 公式**计算航点间的大圆距离：

```javascript
const R = 6371000; // 地球半径（米）
const φ1 = lat1 * π / 180;
const φ2 = lat2 * π / 180;
const Δφ = (lat2 - lat1) * π / 180;
const Δλ = (lng2 - lng1) * π / 180;

const a = sin²(Δφ/2) + cos(φ1) · cos(φ2) · sin²(Δλ/2);
const c = 2 · atan2(√a, √(1−a));
const d = R · c;
```


## 📝 KMZ 文件结构

生成的 KMZ 文件符合 DJI WPML 1.0.6 标准：

```
mission.kmz
└── wpmz/
    ├── template.kml       # 模板定义（区域、参数）
    └── waylines.wpml      # 航线定义（航点、动作）
```

### template.kml
- 任务配置（速度、高度模式、失控动作等）
- 航点航线模板定义
- 云台和相机参数

### waylines.wpml
- 航点列表（坐标、高度、速度）
- 航点动作（云台角度、拍照、录像）
- 航线统计（距离、时间）

## ⚠️ 注意事项

- 前端地图使用 **GCJ-02**（高德地图）
- 导出 KMZ 使用 **WGS84**（GPS 标准）
- 系统自动处理转换，无需手动操作

### 高度设置
- **海拔高度**：需要知道区域的实际海拔
- **相对起飞点**：适用于大部分场景

- 航点航线作为当前重点体验，交互路径更清晰，适合快速完成常规航点任务。

### 文件兼容性
- 生成的 KMZ 文件符合 **WPML 1.0.6** 标准
- 兼容大疆司空 2 和 Matrice 系列无人机
- 建议在导入前备份原有航线

## 🐛 常见问题

### Q: 导入大疆后位置偏移？
A: 已通过坐标转换解决。如果仍有偏移，请检查：
- 地图底图是否为高德地图
- 是否在中国境内（坐标转换仅在中国有效）

### Q: V2 为什么更适合现场快速出线？
A: V2 聚焦航点航线，创建、编辑、生成、下载都集中在本地流程里，减少等待和环境配置成本。

### Q: 本地生成 KMZ 有什么好处？
A: 生成后可以直接下载到本机，便于现场交付、备份、复核，也方便导入大疆司空 2。

### Q: 本地 Cesium 加载有什么好处？
A: 地图核心资源随项目一起提供，部署和演示时更稳定，弱网或内网环境下也更容易启动。
