# DJI 航线生成器 V2 (DJI Waypoint KMZ Generator V2)

一个基于 Vue 3 + CesiumJS 的 DJI 无人机航线规划工具，支持生成符合 WPML 1.0.6 标准的 KMZ 航线文件，可直接导入大疆司空 2 (DJI FlightHub 2) 和 Matrice 系列无人机。

V2 版本是面向本地化、轻量化交付的航点航线版本：当前仅开放航点航线编辑和 KMZ 本地生成能力，其他自动航线算法保留入口展示但暂不可用。

## V2 版本说明

### 和原版的主要区别

| 对比项 | 原版 | V2 版本 |
| --- | --- | --- |
| 航线类型 | 包含巡逻、面状、带状、斜面、几何体等多种航线规划能力 | 仅保留航点航线可用，其他航线类型在首页和创建弹窗中置灰展示 |
| 航线算法 | 内置多种自动航线生成算法 | 已移除非航点航线算法，降低维护成本和运行复杂度 |
| 航线生成 | 部分流程依赖远程服务或对象存储 | 前端/后端均改为本地生成 KMZ，浏览器直接下载 |
| 文件存储 | 使用 MinIO/S3 对象存储保存航线文件 | 不再依赖 MinIO，航线文件生成后保存到本地下载目录 |
| 航线库 | 可能关联远程文件地址、对象 key、签名链接 | 使用本地航线记录，不再展示 MinIO 状态 |
| 地图加载 | Cesium 可能从 unpkg CDN 拉取 | Cesium 改为本地 `/Cesium/Cesium.js` 加载，避免代理或外网失败 |
| 定位逻辑 | 曾包含机场/设备 marker 同步和浏览器定位逻辑 | 删除机场/设备定位同步，仅保留浏览器本机自动定位并切换地图视角 |
| 适用目标 | 功能完整但依赖更多、入口更多 | 更适合只需要航点航线、离线/内网部署、本地下载 KMZ 的场景 |

### V2 新增和调整内容

- 新增航线类型禁用态：保留原首页和创建弹窗的航线类型展示，但除“航点航线”外全部灰色不可用。
- 新增本地航线下载流程：生成 KMZ 后直接触发浏览器下载，不再上传 MinIO。
- 新增本地 Cesium 加载配置：使用 `/Cesium/Cesium.js`，解决 unpkg 访问失败导致地图无法加载的问题。
- 恢复浏览器自动定位：地图初始化后自动请求当前位置，并将相机飞到当前位置。
- 精简后端航线接口：后端生成接口直接返回 KMZ 文件流，不再处理对象存储上传。
- 清理非航点算法和旧编辑入口：减少面状、带状、斜面、几何体等算法代码对运行链路的影响。
- 清理测试、模板、历史资料目录：`.kiro/`、`docs/`、`wpmz/`、`patrol_template/`、`reference_patrol/`、`司空2航线模版/`、`测试文件夹/` 不再作为代码提交内容。

### 当前能力边界

- 可用：航点航线创建、编辑、航点动作配置、KMZ 本地生成、本地下载、地图定位。
- 不可用：面状航线、带状航线、斜面航线、几何体航线、巡逻自动规划等非航点算法。
- 不再依赖：MinIO、AWS S3 SDK、机场/设备 marker 同步。

## ✨ 核心功能

### 🗺️ 航线规划
- **可视化地图编辑**：基于高德地图 + CesiumJS 的 3D 地图界面
- **当前支持航线类型**：
  - **航点航线**：在地图上添加航点，配置高度、速度、云台和动作，生成 KMZ 文件
  - **其他航线类型**：面状、带状、斜面、几何体、巡逻等入口保留但暂不可用
- **航线类型展示**：保留原有多航线类型卡片，用灰色禁用态表示暂不可用能力
- **实时预览**：航线路径实时显示，支持航点路径编辑
- **坐标系转换**：自动转换 GCJ-02（高德）和 WGS84（GPS）坐标系

![商业版航线类型展示](doc/images/business-route-types-gallery.png)

### 🧭 本地定位和地图加载
- **自动定位本机位置**：地图初始化后会请求浏览器定位权限，定位成功后自动切换到当前位置。
- **本地 Cesium 资源**：Cesium 从 `/Cesium/Cesium.js` 加载，不再访问 unpkg CDN。
- **机场/设备定位同步移除**：V2 不再同步机场或设备 marker，避免与本机定位逻辑混淆。

### 📦 本地 KMZ 生成
- **本地下载**：点击生成后直接下载 KMZ 文件。
- **无 MinIO 依赖**：不再上传对象存储，也不再生成 MinIO 签名链接。
- **后端直出文件流**：如使用后端生成接口，会直接返回 KMZ 文件流。

### 📐 高度模式
- **海拔高度 (WGS84)**：绝对海拔高度，基于 WGS84 椭球
- **相对起飞点高度**：相对于起飞点的高度
- **相对地形高度 (实时仿地)**：实时跟随地形起伏，保持相对地面高度恒定

### 🎯 任务配置
- **飞行参数**：速度、高度、起飞安全高度
- **失控动作**：返航、悬停、降落、继续执行
- **完成动作**：返航、降落、悬停、返回首航点
- **爬升模式**：垂直爬升、倾斜爬升

### 📦 KMZ 导入导出
- **导出 KMZ**：生成符合 WPML 1.0.6 标准的 KMZ 文件
- **导入 KMZ**：解析现有 KMZ 文件，恢复航线和配置
- **兼容性**：完全兼容大疆司空 2 和 Matrice 系列无人机

## 📖 使用指南

### 1. 绘制航线

#### 航点航线
1. 选择“航点航线”类型
2. 在地图上点击添加航点
3. 设置航点参数（速度、高度、云台角度、航点动作）
4. 预览航线路径和航点列表
5. 生成并下载 KMZ 文件

#### 其他航线类型
面状航线、带状航线、斜面航线、几何体航线和巡逻自动规划入口会继续显示在创建弹窗中，但 V2 版本中均为灰色禁用状态，暂不能进入编辑器。

### 2. 配置参数

#### 基础参数
- **飞行速度**：1-15 m/s，推荐 10 m/s
- **飞行高度**：20-500 m，推荐 60 m
- **起飞安全高度**：10-200 m，推荐 20 m

#### 高度模式选择
- **海拔高度**：适用于地形平坦区域
- **相对起飞点**：适用于起飞点和目标区域高度相近的场景
- **实时仿地**：适用于山地、丘陵等地形起伏较大的区域

### 3. 生成 KMZ

1. 点击 **生成 KMZ** 按钮
2. 文件会在浏览器中自动下载（`mission.kmz` 或以航线名称命名的 `.kmz` 文件）
3. 导入大疆司空 2 或无人机遥控器

### 4. 导入 KMZ

1. 点击 **导入 KMZ** 按钮
2. 选择已有的 KMZ 文件
3. 系统自动解析并恢复航线和配置

### 5. 本地定位

1. 打开页面后允许浏览器定位权限
2. 地图初始化完成后会自动飞到本机当前位置
3. 如果浏览器拒绝定位，仍可手动拖动地图和创建航点

## 🔧 核心逻辑

### 坐标转换
项目实现了 GCJ-02（火星坐标系）和 WGS84（GPS 坐标系）之间的相互转换：

- **存储**：使用 GCJ-02 坐标（与高德地图一致）
- **显示**：直接使用 GCJ-02 坐标（无偏移）
- **导出**：转换为 WGS84 坐标（大疆标准）

这确保了：
- ✅ 前端点击位置和显示位置完全一致
- ✅ 导入大疆后位置准确无偏移

### 航点航线生成
V2 仅保留航点航线生成逻辑：

1. **航点编辑**：用户在地图上添加航点，并配置高度、速度、云台和动作。
2. **参数归一化**：生成前统一规范任务配置，强制使用航点航线类型。
3. **坐标转换**：导出时将地图坐标转换为 DJI 航线文件需要的 WGS84 坐标。
4. **WPML 生成**：生成 `template.kml` 和 `waylines.wpml`。
5. **KMZ 打包**：使用 JSZip 打包为 KMZ 文件。
6. **本地下载**：浏览器直接下载生成结果。

面状、带状、斜面、几何体等自动规划算法在 V2 中已经移除，不再参与运行。

### 距离和时间计算
使用 **Haversine 公式**计算航点间的大圆距离：

```javascript
const R = 6371000; // 地球半径（米）
const φ1 = lat1 * π / 180;
const φ2 = lat2 * π / 180;
const Δφ = (lat2 - lat1) * π / 180;
const Δλ = (lng2 - lng1) * π / 180;

const a = sin²(Δφ/2) + cos(φ1) · cos(φ2) · sin²(Δλ/2);
const c = 2 · atan2(√a, √(1−a));
const d = R · c;
```


## 📝 KMZ 文件结构

生成的 KMZ 文件符合 DJI WPML 1.0.6 标准：

```
mission.kmz
└── wpmz/
    ├── template.kml       # 模板定义（区域、参数）
    └── waylines.wpml      # 航线定义（航点、动作）
```

### template.kml
- 任务配置（速度、高度模式、失控动作等）
- 航点航线模板定义
- 云台和相机参数

### waylines.wpml
- 航点列表（坐标、高度、速度）
- 航点动作（云台角度、拍照、录像）
- 航线统计（距离、时间）

## ⚠️ 注意事项

### 坐标系统
- 前端地图使用 **GCJ-02**（高德地图）
- 导出 KMZ 使用 **WGS84**（GPS 标准）
- 系统自动处理转换，无需手动操作

### 高度设置
- **海拔高度**：需要知道区域的实际海拔
- **相对起飞点**：适用于大部分场景
- **实时仿地**：需要无人机支持实时测距传感器

### 非航点航线
- V2 版本暂不开放 AI 巡逻、面状扫描、带状扫描、斜面和几何体等自动规划算法。
- 相关入口只作为禁用态展示，后续如恢复算法能力再开放。

### 文件兼容性
- 生成的 KMZ 文件符合 **WPML 1.0.6** 标准
- 兼容大疆司空 2 和 Matrice 系列无人机
- 建议在导入前备份原有航线

## 🐛 常见问题

### Q: 导入大疆后位置偏移？
A: 已通过坐标转换解决。如果仍有偏移，请检查：
- 地图底图是否为高德地图
- 是否在中国境内（坐标转换仅在中国有效）

### Q: 为什么其他航线类型是灰色的？
A: V2 版本只开放航点航线。其他类型保留在界面上是为了维持原首页结构和后续扩展入口，当前不能使用。

### Q: 为什么不需要配置 MinIO？
A: V2 已改成本地生成和下载 KMZ，不再上传对象存储，也不再依赖 MinIO 签名链接。

### Q: 地图为什么不再请求 unpkg？
A: V2 已将 Cesium 改为本地加载，入口配置为 `/Cesium/Cesium.js`，避免外网或代理导致地图核心脚本加载失败。
